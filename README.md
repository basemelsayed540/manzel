# منزّل — تحميل فيديوهات من روابط عامة (Android / Capacitor 6)

تطبيق أندرويد عربي RTL لتحميل الفيديوهات من روابط **عامة** (فيسبوك، يوتيوب، انستجرام، تيك توك) على الجهاز نفسه بدون سيرفر،
باستخدام `youtubedl-android` (yt-dlp + ffmpeg). للاستخدام الشخصي فقط، ويُثبَّت يدوياً كـAPK (ليس لـGoogle Play).

## الهيكل
- `www/` الواجهة (HTML/CSS/JS). تُنشر على GitHub Pages ويحمّلها التطبيق من `server.url`، فأي تعديل يصل بدون APK جديد.
- `android/` مشروع أندرويد + الـplugin (`ManzelPlugin.kt`) والمحرك (`Engine.kt`) والخدمة والحفظ في المعرض والمحدّث.
- `.github/workflows/build.yml` يبني APK موقّعاً وينشره في Release باسم `latest-apk` وينشر الواجهة على Pages.
- `VERSION` رقم إصدار التطبيق (Native). ارفعه (مثلاً `1.0.1`) فقط عند تغيير كود أندرويد.

## الإعداد (مرة واحدة)
1. أنشئ مستودعاً **عاماً** على GitHub باسم `manzel` (عام لأن Pages المجاني والتحديث من Releases يحتاجان ذلك).
2. ارفع محتويات هذا المجلد إليه على الفرع `main`:
   ```
   git init -b main && git add . && git commit -m "منزّل 1.0.0"
   git remote add origin https://github.com/<اسمك>/manzel.git && git push -u origin main
   ```
3. **السرّ الوحيد:** Settings ← Secrets and variables ← Actions ← New repository secret
   - الاسم: `KEYSTORE_B64`
   - القيمة: محتوى الملف `KEYSTORE_B64.txt` كاملاً (سطر واحد).
4. نقرة واحدة تمنع GitHub أن يفعّلها من الـworkflow: Settings ← Pages ← Source = **GitHub Actions**.
5. شغّل الـworkflow (أو ادفع أي تعديل). بعد نجاحه يكون الـAPK هنا:
   `https://github.com/<اسمك>/manzel/releases/download/latest-apk/Manzel.apk`

> احتفظ بملف `manzel-release.p12` في مكان آمن. أي APK لاحق **يجب** أن يُوقَّع بنفس المفتاح وإلا يرفض أندرويد التحديث فوق النسخة المثبّتة.
> كلمة مرور المفتاح مكتوبة في الـworkflow عمداً: السرّ الفعلي هو الملف نفسه.

## كيف تصل التحديثات
| ما تغيّر | كيف يصل |
|---|---|
| الواجهة (`www/`) | تلقائياً عند فتح التطبيق، أو زر التحديث ⟳ (شريط نسبة ثم إعادة فتح وتأكيد رقم الإصدار) |
| محرك yt-dlp | تلقائي مرة يومياً عند الفتح، أو «تحديث المحرك» في الإعدادات |
| كود أندرويد | ارفع `VERSION` ← يبني CI APK جديداً ← التطبيق يعرض شريط «تحديث جديد» ← يحمّله ويفتح شاشة التثبيت (يطلب «مصادر غير معروفة» مرة واحدة) |

## ملاحظات تقنية
- الحفظ في المعرض عبر MediaStore: `Movies/Manzel` (أو `DCIM/Manzel` من الإعدادات)، والصوت في `Music/Manzel`. لا يحتاج صلاحية على أندرويد 10+.
- التحميل داخل Foreground Service مع إشعار تقدم. يعمل ملفان/ثلاثة بالتوازي والباقي بالدور.
- اختيار الصيغة يفضّل H.264 + AAC؛ وإن لم تتوفر يُحوَّل بـ`--recode-video mp4`. «جاهز للستوري» يقص أول 59 ثانية بدون إعادة ترميز عبر MediaMuxer.
- لا تسجيل دخول ولا cookies ولا DRM: الروابط الخاصة تُرفض برسالة واضحة.
